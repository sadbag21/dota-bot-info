# Кэш OpenDota

Ответы хранятся в памяти процесса и исчезают при перезапуске бота.

| Данные | Срок хранения |
| --- | --- |
| Профиль, победы/поражения, герои игрока, общая статистика | 2 минуты |
| Последние матчи | 45 секунд |
| Подробности матча (общие для `/match` и `/impact`) | 10 минут |

После истечения срока следующий запрос получает свежие данные OpenDota.
Просроченные ответы при ошибке сервиса не выдаются. Матчи тоже обновляются:
данные разбора могут дополниться после первого получения.

Лимиты: 512 записей и 16 МиБ сериализованных данных (без учёта накладных
расходов объектов Go). При заполнении удаляется запись с ближайшим сроком
истечения. Просроченные записи очищаются при чтении и записи; фонового
процесса очистки нет. Ответы больше лимита возвращаются без сохранения.

HTTP-ошибки, некорректный JSON, отсутствующие профили и пустые матчи не
кэшируются. Каждый вызов получает собственную копию данных. Доступ к хранилищу
защищён mutex. Одновременные первые запросы одного ключа могут отдельно
обратиться к API; объединения таких запросов пока нет.

Справочник названий героев сохраняет прежний кэш в слое service.
Сроки хранения заданы в `internal/dota/cache.go`, лимиты — в `NewClient`.

Проверки без обращения к внешним сервисам:

```powershell
$env:RUN_OPENDOTA_TESTS="0"
go test ./... -count=1
go vet ./...
```

Проверка гонок (требует настроенного C-компилятора для Go race detector):

```powershell
go test -race ./internal/dota -count=1
```
