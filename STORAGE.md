# Сохранение выбранного игрока

После успешного `/player ID` или кнопки «Профиль» выбор записывается на диск.
Ключ — Telegram-пользователь и чат: участники группы и личный чат независимы.
При следующем запуске `/player`, `/matches`, `/heroes` и `/stats` снова работают
без ID. Явный ID в запросе статистики не изменяет сохранённый выбор.
Анонимные отправители и сообщения от имени чата не создают личных записей.

## Файлы

Настройка `DATA_DIR` задаёт каталог. По умолчанию — `data` относительно рабочей
папки процесса; Docker-образ задаёт `/data`. Файл — `player-selections.json`.
Каталог создаётся автоматически. Файл содержит только версию формата и записи
`chat_id`, `user_id`, `account_id`; токены туда не попадают.

Локальный каталог `data/` исключён из Git и не попадает в Docker-контекст.
Если выбираешь другой каталог внутри репозитория, добавь его в `.gitignore`.
Для резервной копии останови бота и скопируй файл. Для восстановления останови
бота, верни файл в тот же каталог и запусти снова.

## Docker

Используется именованный том `dota-bot-data`, подключённый к `/data`.
Во всех командах создания контейнера из [DOCKER.md](DOCKER.md) есть
`--mount type=volume,source=dota-bot-data,target=/data` и `-e DATA_DIR=/data`.
Созданный из образа том доступен пользователю бота 65532 без root.
Перезапуск и пересоздание контейнера сохраняют данные, если подключён тот же том.
Локальный запуск из GoLand использует другой каталог; он не видит Docker-том автоматически.

При первом переходе со старой версии выбери игрока ещё раз: прежняя версия
хранила выбор только в памяти, поэтому перенести его после остановки нельзя.

## Запись и ошибки

На каждый новый выбор формируется полный JSON во временном файле того же
каталога. После записи, Sync и Close временный файл заменяет основной через
Rename. Только после успешной замены обновляется память. Повторный выбор
того же ID не вызывает запись. Отдельного сохранения при остановке не требуется.

Если запись не удалась, бот показывает профиль с предупреждением и сохраняет
прежний выбор. Файл с неправильным форматом, неподдерживаемой версией,
невалидными ID или дублирующимися ключами останавливает запуск. Автоматического
сброса или перезаписи повреждённых данных нет. Проверь файл/резервную копию и
права каталога, затем перезапусти бота.

Лимиты: 10 000 выбранных игроков, файл до 2 МиБ. Одновременные изменения внутри
процесса защищены mutex. Каталог предназначен для одного процесса бота;
несколько экземпляров не должны одновременно записывать один файл.
Кэш OpenDota/STRATZ и лимит частоты команд остаются в памяти и сбрасываются
при перезапуске.

Тесты проверяют восстановление и замену файла на Windows/Linux, разделение
пользователей и чатов, выбор кнопкой, конкурентное сохранение, отказ записи,
повреждённые/слишком большие файлы и сохранение прежнего выбора при ошибках.
