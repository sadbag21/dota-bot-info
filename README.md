# Dota Bot Info

Telegram-бот на Go для получения информации о Dota 2 игроках по их Dota ID.

Бот использует [OpenDota API](https://www.opendota.com/) и позволяет получить основную информацию об игроке прямо в Telegram.

## Возможности

На данный момент бот умеет:

- искать игрока по Dota ID;
- показывать Steam-ник;
- показывать Dota ID;
- показывать ранг игрока;
- показывать место в Immortal Leaderboard, если оно доступно;
- показывать количество побед;
- показывать количество поражений;
- рассчитывать общее количество матчей;
- рассчитывать winrate;
- показывать ссылку на Steam-профиль.

В дальнейшем планируется добавить:

- последние матчи;
- героев игрока;
- K/D/A;
- статистику по героям;
- анализ последних матчей;
- дополнительные команды и inline-кнопки.
